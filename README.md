# Leggy's Soundpack Swapper
FiveM and GTAV soundpack swapper, thanks claude
This is free to download and use, I made it with claude so I dont really care

# $Install

## Python
Open terminal, and run the command
winget install Python.Python.3.14

## Software
Download the software from this git repository, open it with python

# Usage
The software will auto detect your gta sfx folder, all you need to do is select a folder with your soundpacks, and with gta closed, select your soundpack, and hit install sounds.
